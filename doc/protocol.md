# 串口网关采样报文协议（模拟版 v1）

网关设备通过串口（本项目中由本地 TCP 模拟）连续上送采样报文。
字节流中可能夹杂噪声字节，报文可能分片到达，也可能多包粘连。
所有多字节整数均为**大端（big-endian）**。

## 帧格式（定长 12 字节）

| 偏移 | 字段       | 长度 | 说明                                                        |
| ---- | ---------- | ---- | ----------------------------------------------------------- |
| 0    | SOF 起始标记 | 2    | 固定 `0xAA 0x55`                                            |
| 2    | 通道号     | 1    | 0–15                                                        |
| 3    | 采样序号   | 2    | uint16，0–65535，到顶后回绕为 0                              |
| 5    | 原始值     | 4    | int32，ADC 原始计数（有符号）                                |
| 9    | 校验码     | 1    | 字节 2..8（通道号+序号+原始值）逐字节求和后 `& 0xFF`         |
| 10   | EOF 结束标记 | 2    | 固定 `0x0D 0x0A`                                            |

## 接收方解包规则

1. 在字节流中扫描起始标记 `AA 55`；标记之前的字节视为**噪声**，记录其流内偏移与原始字节后丢弃。
2. 找到起始标记后等待凑齐 12 字节（分片到达时继续等）。
3. 校验结束标记与校验码：
   - 任一不通过 → 该 12 字节记为**坏包**（含原因、流内偏移、原始字节），随后从起始标记后第 1 个字节处重新扫描（允许标记重叠）。
   - 通过 → 解出通道号、采样序号、原始值。
4. 连接中断时若缓冲区残留不足 12 字节的半包，记为**截断包**。

## 序号语义

- 序号按通道独立递增。
- **回绕**：序号从接近 65535 自然回到接近 0（上一序号 ≥ `0xFFF0` 且新序号 ≤ `0x000F`），属于正常计数回绕。
- **设备重启**：序号在远离回绕边界时突然变小，且伴随连接断开（设备重启的物理信号），判定为设备重启。
  - 连接未断开时序号回跳、且该序号在当前 epoch 已入库 → 判为**重发**（重复采样），不计重启；
  - 单帧层面上「重发旧序号」与「重启后从低序号重发」不可区分，因此以连接断开作为重启的佐证信号。
- 两种事件分别记录，并为该通道开启新的 **epoch**（代数），样本以 `(通道, epoch, 序号)` 唯一标识——同一 `(通道, epoch, 序号)` 重复到达视为重复采样，不重复入库。

## 配置生效序号

通道倍率/单位配置携带 `(生效 epoch, 生效序号)`。某条样本适用的是
「生效序号 ≤ 样本序号 的最新版本配置」（按 `(epoch, 序号)` 字典序比较）。
配置适用性只取决于样本自身序号，与样本何时被处理无关：
同一段缓冲数据无论暂停多久再处理，套用的配置都相同。
